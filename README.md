# Smile Project — Data Structure and Pipeline

FaceReader analysis of genuine versus performed smiles.
Ruffman / Kang collaboration, University of Otago.

This document describes how the data is organised, what every file
contains, and the conventions the pipeline relies on. Read
[Naming conventions](#4-naming-conventions--read-this-before-merging-anything)
before joining these files to anything else — the filenames are
misleading in two specific ways.

---

## 2. Running the pipeline

```r
# From the smile_project folder, or with any script open in RStudio.
# Paths are auto-detected — nothing to edit.

source("r_scripts/01_extract_facereader.R")   # ~10 seconds
source("r_scripts/02_analysis.R")             # ~30 seconds
source("r_scripts/03_power_simulation.R")     # 5–15 minutes; run once only
```

Run in order — `02` depends on the outputs of `01`.

**Requirements:** R 4.0+ and `lme4`. Everything else is base R.

```r
install.packages("lme4")
```

If `lme4` is missing, `02_analysis.R` falls back to `nlme` (which ships
with R) but silently drops the stimulus random effect. The analysis log
records which engine was used.

### Pilot mode vs full mode

`02_analysis.R` checks design coverage before modelling.

| Mode | Trigger | Behaviour |
|---|---|---|
| **PILOT** | Fewer than 5 clips in a smile-type cell | Derived variables, descriptives, figures. Inferential models reported as blocked. |
| **PARTIAL** | Both smile types present, only one culture | Genuine vs performed tested; culture terms omitted. |
| **FULL** | All four cells adequately populated | Everything, including the interaction. |

Currently **PILOT** (93 genuine clips, 1 performed). It switches
automatically when the remaining cells arrive — no edits needed.

## 3. Raw data format

FaceReader exports tab-delimited `.txt` with a header block, then a data
table. **Two export types exist and they are not interchangeable.**

### Detailed logs — usable (95 files)

```
Video analysis detailed log

Face Model      General
Calibration     -
Start time      7/7/2026 18:00:03.934
Filename        C:\...\East\C11_noback\Happy 1 CN.mp4_converted_E11HA01-01_noback.mp4
Frame rate      8.000000000


Video Time      Neutral  Happy  ...  Action Unit 01 - Inner Brow Raiser  ...
00:00:00.000    0.4484   0.0443 ...  NotActive                           ...
00:00:00.125    0.4258   0.1110 ...  A                                   ...
```

29 columns: `Video Time` + 8 emotions + 20 action units. Identical layout
in all 95 files.

- **Emotions** — continuous probabilities, 0–1
- **Action units** — ordinal grades: `NotActive`, `A`, `B`, `C`, `D`, `E`
- **`FIT_FAILED`** — appears in either column type when the model could
  not fit that frame. Recoded to `NA`, **never to zero**.

### State logs — NOT usable (13 files)

Filenames end `_state.txt`. These contain only dominant-expression
transitions:

```
Video Time      Dominant Expression
00:00:01.250    Happy
00:00:03.375    Neutral
```

No emotion probabilities, no action units. They **cannot** be used for
peak intensity or duration and must be re-exported from FaceReader as
detailed logs. Affected: all of C15, all of C31, and one C24 clip.

## 4. Naming conventions — read this before merging anything

There are **two independent naming systems** in play, and they disagree.

### The export filename is unreliable

```
Participant_310_Participant_281__chi_hap_6_C025__Analysis_1_video_20260713_142409_detailed.txt
```

- `Participant_310_Participant_281` — **upload IDs, not people.** These
  do not identify a smiler. Do not use them as a person identifier.
- `chi_hap_6` — sequential position, **not the stimulus number.** C24's
  `chi_hap_4` is actually `Happy 5 CN`.

### The internal clip code is authoritative

Read from the `Filename` line inside the file:

```
Happy 1 CN.mp4_converted_E11HA01-01_noback.mp4
                         └──┬──┘
                          E11HA01-01
```

| Part | Meaning |
|---|---|
| `E` | Culture. `E` = East (Chinese). `W` reserved for NZ European. |
| `11` | Smiler / cohort number → `C11` |
| `HA` | Stimulus type. `HA` = humorous → genuine. `SA` = sad → performed. |
| `01` | Stimulus number within that type |
| `-01` | Take number (which smile from that stimulus) |

**Always derive `smiler_id`, `stimulus` and `smile_type` from this code**,
never from the export filename. `01_extract_facereader.R` does this
automatically.

### Built-in integrity check

The source video name (`Happy 1 CN`) and the clip code (`HA`) are two
independent records of the same fact. The extraction script cross-checks
them. Where they disagree it sets `label_conflict = 1`, leaves
`smile_type` blank, and refuses to guess.

One clip currently conflicts: `E25SA07-03` is coded `SA` but its source
video is `Happy 7 CN`.

## 5. Output file reference

### `01_file_manifest.csv` — 1 row per input file (108)

Every file received, whether or not it parsed.

| Column | Description |
|---|---|
| `export_file` | Original filename |
| `status` | `ok` or `state_log_only` |
| `clip_id` | Internal clip code, e.g. `E11HA01-01` |
| `smiler_id` | Person, e.g. `C11` |
| `culture` | `Chinese` / `NZ_European` |
| `smile_type` | `Genuine` / `Fake`; blank if conflicted |
| `label_conflict` | 1 if the two stimulus records disagree |
| `stim_from_label`, `stim_from_code` | The two independent records |
| `stimulus` | Source video, e.g. `Happy 1 CN` |
| `n_frames`, `duration_s`, `frame_rate` | Clip length |
| `n_fitfail_cells` | Count of `FIT_FAILED` cells |

**Start here when a file is missing from the analysis.**

### `02_frames_wide.csv` — 1 row per clip × frame (4,324)

Frame-level time series. Use for plotting time courses.

`clip_id`, `smiler_id`, `culture`, `smile_type`, `stimulus`, `frame`,
`time_s`, then 8 emotion columns (0–1) and 20 AU columns (0–5).

### `03_clip_summary_long.csv` — 1 row per clip × channel (2,660)

Tidy format, 95 clips × 28 channels. **Best for modelling in R.**

| Column | Description |
|---|---|
| `channel` | `AU01`–`AU43`, or an emotion name |
| `channel_type` | `action_unit` / `emotion` |
| `peak` | Maximum intensity |
| `mean_intensity`, `sd_intensity` | Across valid frames |
| `auc` | Trapezoidal area under the curve |
| `prop_active` | Proportion of valid frames active |
| `n_episodes` | Distinct activation bouts |
| `dur_total_s`, `dur_longest_s` | Active duration — **see censoring warning below** |
| `t_peak_s`, `t_peak_prop` | Time of first peak |
| `t_peak_usable` | 0 if start-censored, making `t_peak_s` meaningless |
| `censored_start` | 1 if active in the **first** frame — onset unobserved |
| `censored_end` | 1 if active in the **final** frame — offset unobserved |
| `n_valid_frames`, `n_missing_frames` | Excludes `FIT_FAILED` |

### `04_clip_summary_wide.csv` — 1 row per clip (95), 290 columns

Same content, one row per clip. **This is the SPSS import file.**
Variable names are SPSS-safe (longest 16 characters).

Naming: `{channel}_{metric}`, e.g. `AU12_pk`, `Happy_prop`.

| Suffix | Metric |
|---|---|
| `_pk` | Peak intensity |
| `_mn` | Mean intensity |
| `_prop` | Proportion of frames active |
| `_durmax` | Longest single bout (seconds) |
| `_durtot` | Total active time (seconds) |
| `_tpk` | Time to peak (seconds) |
| `_auc` | Area under curve |
| `_neps` | Number of episodes |
| `_cens0` | Start-censored flag |
| `_cens1` | End-censored flag |

### `05_channel_dictionary.csv` — 28 rows

Maps codes to muscle names.

| Code | Muscle | | Code | Muscle |
|---|---|---|---|---|
| AU01 | Inner Brow Raiser | | AU15 | Lip Corner Depressor |
| AU02 | Outer Brow Raiser | | AU17 | Chin Raiser |
| AU04 | Brow Lowerer | | AU18 | Lip Pucker |
| AU05 | Upper Lid Raiser | | AU20 | Lip Stretcher |
| **AU06** | **Cheek Raiser** *(Duchenne marker)* | | AU23 | Lip Tightener |
| AU07 | Lid Tightener | | AU24 | Lip Pressor |
| AU09 | Nose Wrinkler | | AU25 | Lips Part |
| AU10 | Upper Lip Raiser | | AU26 | Jaw Drop |
| **AU12** | **Lip Corner Puller** *(the smile)* | | AU27 | Mouth Stretch |
| AU14 | Dimpler | | AU43 | Eyes Closed |

Emotions: Neutral, Happy, Sad, Angry, Surprised, Scared, Disgusted,
Contempt.

### `07_analysis_dataset.csv` — 1 row per analysed clip (94)

`04_clip_summary_wide.csv` plus derived variables, after exclusions.

| Derived variable | Definition |
|---|---|
| `duchenne_prop` | Of frames where AU12 is active, proportion also having AU06 active. `NA` if AU12 never fires. |
| `au12_rise_rate` | Peak AU12 ÷ time from onset to peak. **Only where onset was observed** — currently 42 of 93 clips. |
| `au12_smooth` | Mean absolute frame-to-frame change in AU12. Lower = smoother. |
| `au12_n_bouts` | Distinct AU12 activation episodes. |

### Other outputs

| File | Contents |
|---|---|
| `06_data_quality_report.txt` | Inventory, coverage, censoring audit, conflicts |
| `08_descriptives_by_condition.csv` | Means, SDs, ranges by cell |
| `09_confirmatory_results.csv` | Four pre-specified tests (full mode only) |
| `10_exploratory_results.csv` | FDR-corrected AU screen (full mode only) |
| `11_analysis_log.txt` | Audit trail of every decision applied |
| `12_power_simulation.csv` | Power grid by smiler count and effect size |

## 6. Coding decisions

Applied consistently by the pipeline. Changing any of these means
re-running everything.

| Decision | Rule |
|---|---|
| AU intensity | `NotActive`=0, A=1, B=2, C=3, D=4, E=5, `FIT_FAILED`=`NA` |
| AU active | Intensity ≥ 1 (grade A and above) |
| Emotion active | Probability ≥ 0.5 |
| Smile type | `HA` stimulus = Genuine, `SA` = Fake |
| Duration covariate | Applied to `_pk`, `_tpk`, `_durtot`, `_durmax`, `_auc`, `_neps`. Peak measures need it because the maximum of a longer series is stochastically larger — see Known issues. Scale-free proportions exempt |
| Missing data | `FIT_FAILED` → `NA`, **never zero** |
| Unit of analysis | One smile episode, not one person |

Thresholds are configurable at the top of each script
(`AU_ACTIVE_MIN`, `EMO_ACTIVE_MIN`).

## 7. Known issues

### Right-censoring — affects any duration measure

Clips were cut tightly around each smile, so many action units are
already active in the first frame or still active in the last.

| Unit | Start-censored | End-censored |
|---|---|---|
| AU12 (Lip Corner Puller) | 28% | **69%** |
| AU06 (Cheek Raiser) | 21% | **63%** |
| AU25 (Lips Part) | 27% | 46% |
| AU43 (Eyes Closed) | 65% | **91%** |

**Consequence:** `dur_total_s` and `dur_longest_s` are **lower bounds,
not measurements**, for any unit with a high censoring rate. Do not
report mean durations for AU06, AU12, AU25 or AU43 without saying so.

**Safe to use:** `peak`, `mean_intensity`, `prop_active` — all unaffected.

Full table in `06_data_quality_report.txt`.

### Frame rate is 8 fps, not 30

All exports report 8 fps, apparently downsampled during the
`_converted_` step. Every timing measurement is quantised to 125 ms.

### Nine genuine clips contain no smile

AU12 never activates in any frame; mean peak happiness 0.08 against 0.75
elsewhere. Not tracking failures — zero `FIT_FAILED` cells and other AUs
fire normally, so it looks like mis-segmentation. Currently **retained**
in the analysis set pending a decision on the exclusion rule proposed in
the Statistical Analysis Plan.

### Peak intensity is confounded with clip length

Peak AU12 rises with clip duration (β = 0.26 per SD, 95% CI [0.08, 0.44]).
This is a sampling artefact — the maximum of a longer series is
stochastically larger. Truncating every clip to a common 21-frame window
removes the association entirely (β = 0.03, p = .76).

**Consequence:** if genuine and performed clips differ in length, an
uncorrected comparison of `_pk` measures is biased. The pipeline covaries
clip duration for all peak outcomes. `duchenne_prop` and `_prop` measures
are scale-free and unaffected.

### Grade E is effectively unused

Under 1% of active cells, and never once for AU06. The nominally
six-level scale has five working levels, which slightly weakens treating
it as continuous.

### Design coverage

Currently 93 genuine and 1 performed smile from 16 smilers. The
genuine-versus-performed contrast is **not testable** until the remaining
three cells arrive: Chinese Fake, NZ European Genuine, NZ European Fake.

## 8. Quick recipes

```r
# Load the analysis-ready dataset
dat <- read.csv("results_outputs/07_analysis_dataset.csv")

# Duchenne markers for genuine smiles
subset(dat, smile_type == "Genuine",
       select = c(clip_id, smiler_id, AU06_pk, AU12_pk, duchenne_prop))

# Clips per person — note the unbalance
table(dat$smiler_id)

# Plot one clip's AU12 time course
fr <- read.csv("results_outputs/02_frames_wide.csv")
d  <- subset(fr, clip_id == "E11HA02-04")
plot(d$time_s, d$AU12, type = "l", ylim = c(0, 5),
     xlab = "Time (s)", ylab = "AU12 intensity")

# How censored is a given unit?
mean(dat$AU12_cens1)   # proportion still active in the final frame
```

**Merging with external data** (e.g. human judgement ratings): join on
`clip_id`. It is the only stable unique key. Do not join on filename.
